Product Update 23

Pauline Pham
-April 9, 2026
Hi there,
Describe what you want an agent to do. Watch it get built. That's Sidekick, a new AI co-pilot embedded in the Agent Builder that drafts instructions, recommends tools, and suggests improvements: all as reviewable diffs. We also expanded voice to 21 languages, shipped GPT 5.4, and added ten new MCP integrations, including Attio, Fathom, Miro, Front, and more.
Here's everything that's new in Dust.

🧑‍✈️ Describe it. Dust builds it.

Sidekick is a new AI agent embedded directly in the Agent Builder. Describe what you want your agent to do in plain language or turn a conversation into a new agent: Sidekick drafts the instructions, recommends tools and skills, and surfaces improvements as reviewable inline diffs. One click to accept, one click to reject. You stay in full control.
Here's what you can do with it:
  • Start from scratch — Describe your use case. Sidekick asks a couple of clarifying questions and produces a full agent configuration ready to review.
  • Improve existing agents — Open any agent in the Builder. Sidekick reads your current config, checks feedback and usage metrics, and surfaces concrete suggestions.
  • Templates, but smarter — Selecting a template from the gallery no longer drops static instructions. It opens Sidekick pre-loaded with that template's context to build a version customized to your actual workflow.
  • Convert a conversation to an agent — Had a great conversation in Dust? Hit "Convert to agent" and Sidekick drafts an agent that replicates the same tools, knowledge, and workflow.
📖 Read the docs

🌐 Your browser has a point of view.

The Chrome extension has been rebuilt from the ground up. It now matches the full web app experience: the sidebar, the input bar, and conversations. Everything you're used to in Dust, without opening a new tab.
The extension also gives agents real browser awareness:
  • Tab content & screenshots — Agents automatically detect when they need the current page and ask for permission to access it. No more manual attachments.
  • Multi-tab support — Agents can work across multiple open tabs at once.
  • Page interaction — Agents can use mouse clicks and keystrokes to interact with the page: fill forms, click buttons, navigate.
  • MCP tools — agents can use all your existing MCP tools (Notion, Gmail, etc.) directly from the sidebar.
Also available on Arc, Microsoft Edge, and other Chromium-based browsers. Read the docs 📖

🔗 Share a Frame with exactly who you want.

Now you can invite specific people by email. They get a link, they see the Frame, done.
Finer control over who sees what, without changing permissions for everyone else. Perfect for sharing work with a specific collaborator, a stakeholder review, or a client-facing deliverable.
📖 Read the docs

🗣️ It understands you. In 21 languages.

Dust voice features now support 21 languages, up from 9. Voice selection is smarter too: you get a better-matching voice for your language and use case, fewer jarring defaults, and more natural conversations.
Whether you're transcribing a meeting in Japanese or generating spoken summaries in Portuguese, the experience is smoother, more natural, and works out of the box.

🧠 5.4 reasons to try it.

OpenAI's latest model is now available in the Agent Builder and powers the gpt5 and gpt5-thinking global agents.

🧮 The MCP Corner

A record month. Ten new MCP servers ship with this update, connecting Dust to your CRM, hiring pipeline, meeting notes, visual workspace, support inbox, and more.
Ashby — Now available in all workspaces. Search candidates, retrieve interview feedback, read and create profile notes, and pull report data as CSV. Read the docs
Attio — Connect your Attio CRM via OAuth and give agents direct access to your workspace. Search and manage contacts, companies, deals, tasks, notes, emails, and call recordings. Read the docs
Fathom — Agents can now access your Fathom meeting data directly in conversation. Filter meetings by date, team, or domain, pull AI summaries and action items, retrieve full transcripts, and match meetings to CRM records. Read the docs
Front — Now available in all workspaces. Search and read conversations, look up contacts, list inboxes and tags, create outbound conversations, draft replies, send messages, add comments, and tag or link conversations. Read the docs
Hex — One-click support for Hex's remote MCP server. Search projects and use Threads to ask questions and iterate on analysis directly from Dust. Read the docs
Miro — Create diagrams, build tables, read and edit documents, and explore your entire visual workspace without leaving your conversation. Read the docs
Salesforce — Agents can now create and update records: companies, notes, opportunities, and more. Made safer by the introduction of medium-stakes confirmations. Available to Enterprise customers. Read the docs
Salesloft — Now available in all workspaces. Retrieve your Salesloft actions filtered to due or overdue, giving sales reps instant visibility into what needs attention. Read the docs
Semrush — SEO insights, keyword analysis, and competitor intelligence, all from your Dust conversations. Read the docs
Slab — Now available in all workspaces. Search posts by keyword with filters for topic and status, read full content, list topics, and retrieve metadata. Read the docs

➕ And more...

Your slides leave Dust now. Slideshow Frames now bundle navigation controls and export as multi-page PDFs, with each slide rendered as a full page with proper page breaks. Share and print agent-generated decks outside of Dust. Works on all newly created Frames.
Google Drive tool improvements. You can now create Google Docs, Sheets, and Slides in a specific folder and update the file sharing permissions.
More granular permissions for MCPs. Admins can now uncheck optional permissions (e.g. write access, shared mailboxes, contacts) when installing any tool that allows it. The restriction is then enforced for all users' personal connections.
Trigger all agents you need. You can now create your own trigger on every agent they have access to, without being an editor, including default agents as @dust and @deep-dive.
Discover Skills. Add a the Discover Skills skill to discover workspace skills.
